# Local additions to learn

These rules come from this repo's workflow doc. They add to the upstream
instructions in SKILL.md, and they win where the two differ.

- **Its own folder.** Run only in a learning folder. If the current folder is
  a product repo (it holds `docs/sdlc/` or source code under version
  control), stop and ask the user for a learning folder, because lesson files
  would otherwise mix into the product's history.
- **Sources.** Ground each lesson in primary, high-trust sources and cite
  them. For a single fact a lesson needs, the `research` skill can find it.
