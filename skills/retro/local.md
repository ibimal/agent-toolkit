# Local additions to retro

These rules come from this repo's workflow doc. They add to the upstream
instructions in SKILL.md, and they win where the two differ.

- **Propose, then wait.** Present the ranked fixes and apply only the ones
  the user accepts.
- **Where an accepted fix goes,** in order of preference: a check or command;
  a skill edit through `/to-skill`; a `CLAUDE.md` line.
- **Standards file.** Where the instructions below say `CODING_STANDARDS.md`,
  use `REVIEW.md`.
- **Not codify.** What one change taught belongs to `codify`. This skill
  looks at how the session itself went.
